# 0001. Scope all data by dataset; ship a synthetic demo league

Date: 2026-10-10 · Status: accepted

## Context
The first version was built on data from the Premier League website's API and committed those snapshots to the
repository. The site's terms of use say its material may not be reproduced, re-utilised or redistributed, and
they prohibit creating a database from downloaded material. A public repository or image containing that data
would redistribute it. Trained models were also affected, because the feature models keep their training frame,
and so were the backtest predictions file and the screenshots.

## Options
1. **Keep the data, add a disclaimer.** That does not change what is being redistributed.
2. **Let each user extract it themselves.** This is still the same restricted source, so it fixes nothing about
   permission. It also makes a fresh clone depend on the network.
3. **A permissively licensed real source.** openfootball/football.json dedicates its data to the public domain.
   It has results only (no shots or possession), and it is community-maintained.
4. **A synthetic league generated by the project.** It is shareable without question and reproducible offline,
   and its true probabilities are known. On the other hand it is not real football.

## Decision
Every path the pipeline writes is scoped by `EPL_DATASET`: `data/<dataset>/`, `data/<dataset>.db` and
`data/artifacts/<dataset>/`. A registry (`src/epl/data/datasets.py`) records each dataset's license and whether it
may be redistributed. The default dataset is **`demo`**, a synthetic 20-club league (option 4).
**`openfootball`** (option 3) is an optional real-data source, and **`premier-league`** remains available for
personal local use only. Restricted data is kept out of distribution by allow-lists in `.gitignore` and
`.dockerignore`. `scripts/check_distribution.py` verifies the files Git would track and the actual Docker build
context, and CI runs it.

## Consequences
- A fresh clone builds, tests and serves with no network access and no restricted data.
- Demo results measure the software and models, not real-world skill. The synthetic truth adds an **oracle**
  ceiling to every report, which shows how much of the achievable improvement each model captures.
- The generator was calibrated against three aggregate Premier League statistics, so its difficulty is
  realistic: final-points spread, home-win rate and goals per match. Draws remain slightly under-represented,
  because goals are independent Poisson.
- Results measured on Premier League data stay in the author's local environment, and the README reports them
  separately. Whether even aggregate results may be published under the site's terms is not established.
